    Progress

      What GO does

      • Checks the store is active, every pack and bundle has a live Lemon Squeezy product, and the checkout key is set. If any of that fails, nothing changes and the reason shows here.
      • Writes the Lemon Squeezy variant ids into the site, rebuilds it, deploys it and pushes the site repo, so every Buy button opens a real checkout.
      • Updates the marketing facts so packs read as for sale instead of available soon.
      • Releases the held launch posts in the outbox so they show as ready on the marketing page. Nothing is posted for you.
      • Emails the waitlist once (at most 100 per day, with an unsubscribe link and the postal address), only if the email sender and postal address are set up.
      • Pings search engines with the sitemap and logs each step to the event log.
