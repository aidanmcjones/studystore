Qbank for Mac

A dark, fast flashcard app for your Anki decks.

Qbank is a macOS flashcard app that opens the decks you already have. It adds exam-deadline pacing, a shared FSRS optimizer, Restudy and a command palette, with Browse, Add and Stats inside the main window.

What it is

Qbank is an Anki-compatible flashcard app for the Mac, built on the open-source Anki code with a dark redesign. One window holds everything: study, decks, Browse, Add and Stats.

  • Exam-deadline pacing. Set an exam date on a deck and choose what happens after it: pause or keep reviewing.
  • Shared FSRS optimizer. One FSRS setting for the collection, with per-deck study limits and desired retention in a single Settings page.
  • Restudy. Go back over cards you want another pass on.
  • Command palette. Search decks, cards, tags and actions from one box.
  • Browse, Add and Stats in the window. No separate floating windows for the everyday tools.
  • Dark only. A single dark theme with an accent color and optional video backdrop on the deck list.

Who it is for

  • Pre-med students and MCAT test takers who study from card decks, including the StudyStore MCAT packs.
  • Any student who already uses Anki decks and wants a different interface and a deadline-aware schedule.

Works with your existing Anki decks

Import .apkg and .colpkg files, and plain text files, with Import file in the sidebar. Qbank keeps its own data folder, separate from other flashcard apps, so trying it does not touch an existing collection.

System requirements

  • A Mac with Apple Silicon (M1 or later). Intel Macs are not supported in this release.
  • macOS 13 (Ventura) or later. The download file is named %%qb_dmg%% (mac-apple means Apple Silicon).

How to open

Version 1 is not signed with an Apple Developer ID, so macOS blocks the first launch. This is expected. Open it once like this:

  1. Open the DMG and drag Qbank to Applications.
  2. In Applications, right-click Qbank and choose Open, then choose Open in the dialog.
  3. On macOS 15 and later, if there is no Open button, double-click Qbank once, then go to System Settings, Privacy and Security, scroll to the message about Qbank and click Open Anyway. Confirm with your password.

After that it opens normally.
