What this site collects

This website has no accounts, no cookies, and only two optional forms: the launch list and the problem report form, both described below. It has no advertising or third-party tracking scripts. To learn which wording and layouts help visitors, the site runs a small first-party measurement script that we wrote ourselves (/assets/js/exp.js).

That script stores a random identifier in your browser's local storage (not a cookie). It is generated on your device, is not linked to your name, email, or account, and you can clear it at any time by clearing this site's data in your browser. It also remembers which version of a page element (for example, a headline) you were shown, so you see the same version on each visit.

The script sends us these anonymous events: that a page was viewed, that you clicked a main button, a Buy button, or a free-sampler link, and that you joined the launch list (the event says only that a signup happened on that page, never your email). Each event contains only: the time, the random identifier, the page path, the version of each page element you were shown, the event name, the domain of the site that linked you here (for example, google.com, not the full address), and any utm_source and utm_campaign tags in the link you followed. These events never include your IP address, your browser's user agent, your location, or anything you type. To stop abuse, the server counts requests per visitor for rate limiting: it uses your IP address in memory and keeps only a one-way hash of it, combined with the current minute, in Cloudflare's temporary edge cache for about a minute. Your IP address is never written to our database.

If your browser sends a Do Not Track or Global Privacy Control signal, the script sends nothing at all. If you block JavaScript, the site works normally and nothing is sent.

The site is hosted by Cloudflare, which, like any web host, may process standard request data under its own privacy policy. Events are stored in a Cloudflare database we control and are used only in aggregate to improve this site. We do not sell or share them.

If you use the "Report a problem or suggest something" form, we store only the page address, the category you pick and the text you type (plus an optional card or question number); no email, IP address or cookies. The same temporary rate-limit hash described above is used to stop abuse.

Purchases

When you click Buy you leave this site for a {{merchant}} checkout. The Buy link carries the versions of the page elements you were shown and any utm tags (for example, home_hero=b or utm_source=reddit), so we can tell which wording led to a purchase. It carries no personal data from this site. {{merchant}} is the merchant of record: it collects your payment and contact details, calculates and remits tax, and delivers your download. We do not see or store your card details. {{merchant}}'s privacy policy governs that data. Through {{merchant}} we may receive limited order information, such as your email address and order number, so we can provide support and refunds.

Email

If you email us, we use your message only to reply to you. We do not sell or share your information.

Launch list (email)

We store an email address only if you type it into the "Get launch day access" form and submit it. With it we store the test month you pick (optional), the page the form was on, any utm_source and utm_campaign tags in the link that brought you here, the signup time, and a random unsubscribe code. We do not store your IP address, user agent or any cookie with it.

We use your address to send one email when checkout opens. After that we email you only if you opt in to optional study emails. We never sell, rent or share your address, and we do not add it to any advertising platform. When we send email, a mail delivery provider processes the address for us only to deliver it.

Every email has an unsubscribe link that works in one click. To have your address deleted entirely, email us at the support address below and we will remove it.
