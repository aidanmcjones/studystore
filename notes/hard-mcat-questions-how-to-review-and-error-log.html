A hard question is only useful if you extract something reusable from it. Review each miss, name the cause, and write one rule you can apply next time. Doing more questions without this tends to repeat the same errors.

Step 1: classify the miss

Error typeSignFix
Content gapYou did not know the factAdd a card or note
MisreadYou knew it but missed a word or unitUnderline the ask before answering
ReasoningYou chose a plausible trapWrite why the right answer wins
TimingYou guessed or rushedSkip and return
Lucky guessRight for the wrong reasonTreat it as a miss

Step 2: log it

Keep one line per question:

  • Topic and source.
  • Error type.
  • The rule, in one sentence ("a negative E means nonspontaneous").
  • Date to retest.

Step 3: retest

Put content gaps into spaced repetition. Reread the log weekly and redo a few missed questions cold after a delay. If an error type dominates, change your process, not your content.

Reviewing a correct answer

Explain why each wrong option is wrong. This is where trap patterns appear, such as extreme wording or reversed cause and effect.

Common traps

  • Reading the explanation and moving on. Recognition is not recall.
  • Logging only content gaps.
  • Reviewing only wrong answers. Check low-confidence correct ones too.

One-minute recap

  • Classify, write the rule, retest.
  • Treat lucky guesses as misses.
  • Fix the process if one error type dominates.
