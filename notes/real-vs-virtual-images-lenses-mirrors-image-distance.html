A real image forms where light rays actually converge, so it can be projected on a screen. A virtual image forms where rays only appear to come from, so it cannot be projected. The sign rule that ties both together: real images have positive image distance (di > 0) and virtual images have negative image distance (di < 0), using the convention 1/f = 1/do + 1/di.

Where the image forms

DeviceReal image sideVirtual image side
MirrorSame side as the object (in front)Behind the mirror
LensOpposite side from the objectSame side as the object

For mirrors, light bounces back, so "in front" is where light goes. For lenses, light passes through, so "beyond the lens" is where light goes. In both cases, positive di means the image is on the side where the light really goes.

Quick sign table

QuantityPositive whenNegative when
doReal object (almost always)Virtual object (rare)
diReal imageVirtual image
fConverging: concave mirror, convex lensDiverging: convex mirror, concave lens
m = -di/doUpright imageInverted image

So a real image is always inverted for a real object (m < 0), and a virtual image is always upright (m > 0).

What each device can do

  • Plane mirror: always a virtual, upright image, same size, di = -do.
  • Convex mirror and concave lens (diverging): always a virtual, upright, reduced image, for any real object.
  • Concave mirror and convex lens (converging): the image depends on object position. Object beyond f gives a real, inverted image. Object inside f gives a virtual, upright, enlarged image (a magnifying glass or makeup mirror).

Worked example 1: object inside the focal length

A concave mirror has f = +10 cm. An object sits 4 cm in front of it.

  1. 1/di = 1/f - 1/do = 1/10 - 1/4 = -0.15, so di = -6.7 cm.
  2. Negative di: virtual, behind the mirror.
  3. m = -(-6.7)/4 = +1.7: upright and enlarged.

Worked example 2: object beyond the focal length

A convex lens has f = +15 cm. An object is 30 cm away.

  1. 1/di = 1/15 - 1/30 = 1/30, so di = +30 cm.
  2. Positive di: real, on the far side of the lens.
  3. m = -30/30 = -1: inverted, same size. The object sits at 2f.

Worked example 3: diverging lens

A concave lens has f = -20 cm and the object is 40 cm away.

  1. 1/di = -1/20 - 1/40 = -3/40, so di = -13.3 cm.
  2. Virtual, same side as the object, m = +0.33: upright and reduced.

Common traps

  • Thinking virtual means "not there." Your eye still sees a virtual image. It just cannot land on a screen.
  • Using the same side rule for mirrors and lenses. Real images are on the object side for mirrors and the opposite side for lenses.
  • Dropping the sign of f. Diverging devices have negative f.
  • Expecting a real image from a diverging device. With a real object it never happens.

One-minute recap

Real image: di positive, inverted, projectable. Virtual image: di negative, upright, not projectable. Converging devices can make either, depending on whether the object is beyond or inside f. Diverging devices make only virtual, upright, reduced images.

Check yourself: 5-question mini-quiz

Try each question first, then click it to reveal the answer.

1. What sign does the image distance have for a virtual image?

Negative, in the convention 1/f = 1/do + 1/di.

2. A real object is placed beyond the focal point of a convex lens. Is the image real or virtual, upright or inverted?

Real and inverted.

3. Which devices produce only virtual images from a real object?

Plane mirrors, convex mirrors and concave (diverging) lenses.

4. A concave mirror (f = 12 cm) has an object 6 cm away. What is the image distance?

1/di = 1/12 - 1/6 = -1/12, so di = -12 cm, a virtual image behind the mirror.

5. Where does a real image form for a lens versus a mirror?

For a lens, on the side opposite the object. For a mirror, on the same side as the object.
