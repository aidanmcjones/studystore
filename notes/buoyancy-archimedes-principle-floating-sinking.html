A fluid pushes up on any object in it with a force equal to the weight of the fluid the object displaces. That is Archimedes' principle. The MCAT uses it to ask whether something floats, how much of it is submerged, and what a scale reads when it hangs underwater.

Core formulas

QuantityFormula
Buoyant forceFB = ρfluid Vsubmerged g
WeightW = ρobject Vobject g
Apparent weight (fully submerged)Wapp = W - FB
Floating, submerged fractionVsub/V = ρobject / ρfluid
Specific gravityρobject / ρwater

The volume that counts is the volume of fluid displaced, which is the submerged volume, not the whole object.

Float or sink

ComparisonResult
ρobject < ρfluidFloats, partly submerged
ρobject = ρfluidNeutrally buoyant, hovers
ρobject > ρfluidSinks

A floating object is in equilibrium, so FB = W. That is why the submerged fraction equals the density ratio.

Worked example

A block of density 600 kg/m3 floats in water (1000 kg/m3).

  • Submerged fraction = 600/1000 = 0.6, so 60% is below the surface.
  • In a fluid of density 1200 kg/m3 the fraction is 600/1200 = 0.5.
  • A 2 kg mass of density 4000 kg/m3 hung fully in water has V = 0.0005 m3, so FB = 1000 x 0.0005 x 10 = 5 N. Its weight is 20 N, so the scale reads 15 N.

Common traps

  • Using the object's density in FB. Buoyant force uses the fluid density.
  • Using the full volume for a floating object. Use the submerged part.
  • Thinking heavier objects always sink. Only density matters, so a steel ship floats.
  • Forgetting the object's own weight when finding apparent weight.

One-minute recap

FB = ρfluidVsubg. Floats if the object is less dense than the fluid. Floating means FB = W, so submerged fraction = density ratio. Apparent weight = W - FB.

Check yourself: 5-question mini-quiz

Try each question first, then click it to reveal the answer.

1. What determines the size of the buoyant force on a submerged object?

The weight of the fluid it displaces, which is fluid density times submerged volume times g.

2. A block with density 800 kg/m3 floats in water. What fraction is submerged?

0.8, the ratio of object density to fluid density.

3. A floating object is moved from water to a denser fluid. What happens to the submerged volume?

It decreases, because less volume is needed to displace the same weight.

4. A 20 N object weighs 15 N when fully submerged. What is the buoyant force?

5 N.

5. Does buoyant force on a fully submerged object change with depth in an incompressible fluid?

No, because the displaced volume and fluid density stay the same.
