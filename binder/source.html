What is in a tarball

  • engine/: the application source.
  • addon/: the Binder add-on source.
  • SOURCE-README.txt: the commits used, and the pinned commits of the public upstream translation repositories that a source archive does not contain.
  • Personal data and development-only tooling are not included.

Verify a download

Compare the SHA-256 listed for each release with shasum -a 256 <file>.
