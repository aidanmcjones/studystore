How to open

Mac

Version 1 is not signed with an Apple Developer ID, so macOS blocks the first launch. This is expected. Open it once like this:

  1. Open the DMG and drag Binder to Applications.
  2. In Applications, right-click Binder and choose Open, then choose Open in the dialog.
  3. On macOS 15 and later, if there is no Open button, double-click Binder once, then go to System Settings, Privacy and Security, scroll to the message about Binder and click Open Anyway. Confirm with your password.

Windows

Version 1 is not signed with a Microsoft certificate, so Windows SmartScreen may warn on first run. This is expected.

  1. Run binder-1.0.0-win-x64.exe. It installs for your account only, no admin needed.
  2. If SmartScreen says Windows protected your PC, choose More info, then Run anyway.
  3. Open Binder from the Start menu or the Desktop shortcut.
