Integrated rate laws give concentration as a function of time. The order is read from which plot of the data is a straight line.

## The three orders

| Order | Integrated law | Straight-line plot | Slope | Half-life |
|---|---|---|---|---|
| Zero | [A] = [A]<sub>0</sub> - kt | [A] vs t | -k | [A]<sub>0</sub> / 2k |
| First | ln[A] = ln[A]<sub>0</sub> - kt | ln[A] vs t | -k | 0.693 / k |
| Second | 1/[A] = 1/[A]<sub>0</sub> + kt | 1/[A] vs t | +k | 1 / (k[A]<sub>0</sub>) |

## Units of k

Zero order: M/s. First order: 1/s. Second order: 1/(M s).

## Worked example

A first order decay has k = 0.0231 per minute. Half-life = 0.693 / 0.0231 = 30 minutes. After 90 minutes (3 half-lives) one eighth remains.

## Key point on half-life

Only first order has a half-life that does not depend on starting concentration. Zero order half-lives shrink as the reactant is used up; second order half-lives grow.

## Common traps

- **Using 0.693 / k for every order.** It only works for first order.
- **Forgetting the sign.** The slope is -k for zero and first order, +k for second.
- **Mixing up this with initial rates.** Initial rates compare experiments; integrated laws follow one run over time.

## One-minute recap

- Linear plot picks the order: [A], ln[A], 1/[A].
- k units: M/s, 1/s, 1/(M s).
- Constant half-life means first order.
