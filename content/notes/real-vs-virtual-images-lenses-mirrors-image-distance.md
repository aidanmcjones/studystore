A **real image** forms where light rays actually converge, so it can be projected on a screen. A **virtual image** forms where rays only appear to come from, so it cannot be projected. The sign rule that ties both together: **real images have positive image distance (d<sub>i</sub> &gt; 0) and virtual images have negative image distance (d<sub>i</sub> &lt; 0)**, using the convention 1/f = 1/d<sub>o</sub> + 1/d<sub>i</sub>.

## Where the image forms

| Device | Real image side | Virtual image side |
|---|---|---|
| Mirror | Same side as the object (in front) | Behind the mirror |
| Lens | Opposite side from the object | Same side as the object |

For mirrors, light bounces back, so "in front" is where light goes. For lenses, light passes through, so "beyond the lens" is where light goes. In both cases, **positive d<sub>i</sub> means the image is on the side where the light really goes.**

## Quick sign table

| Quantity | Positive when | Negative when |
|---|---|---|
| d<sub>o</sub> | Real object (almost always) | Virtual object (rare) |
| d<sub>i</sub> | Real image | Virtual image |
| f | Converging: concave mirror, convex lens | Diverging: convex mirror, concave lens |
| m = -d<sub>i</sub>/d<sub>o</sub> | Upright image | Inverted image |

So a real image is always **inverted** for a real object (m &lt; 0), and a virtual image is always **upright** (m &gt; 0).

## What each device can do

- **Plane mirror:** always a virtual, upright image, same size, d<sub>i</sub> = -d<sub>o</sub>.
- **Convex mirror and concave lens (diverging):** always a virtual, upright, reduced image, for any real object.
- **Concave mirror and convex lens (converging):** the image depends on object position. Object beyond f gives a real, inverted image. Object inside f gives a virtual, upright, enlarged image (a magnifying glass or makeup mirror).

## Worked example 1: object inside the focal length

A concave mirror has f = +10 cm. An object sits 4 cm in front of it.

1. 1/d<sub>i</sub> = 1/f - 1/d<sub>o</sub> = 1/10 - 1/4 = -0.15, so d<sub>i</sub> = **-6.7 cm**.
2. Negative d<sub>i</sub>: virtual, behind the mirror.
3. m = -(-6.7)/4 = **+1.7**: upright and enlarged.

## Worked example 2: object beyond the focal length

A convex lens has f = +15 cm. An object is 30 cm away.

1. 1/d<sub>i</sub> = 1/15 - 1/30 = 1/30, so d<sub>i</sub> = **+30 cm**.
2. Positive d<sub>i</sub>: real, on the far side of the lens.
3. m = -30/30 = **-1**: inverted, same size. The object sits at 2f.

## Worked example 3: diverging lens

A concave lens has f = -20 cm and the object is 40 cm away.

1. 1/d<sub>i</sub> = -1/20 - 1/40 = -3/40, so d<sub>i</sub> = **-13.3 cm**.
2. Virtual, same side as the object, m = +0.33: upright and reduced.

## Common traps

- **Thinking virtual means "not there."** Your eye still sees a virtual image. It just cannot land on a screen.
- **Using the same side rule for mirrors and lenses.** Real images are on the object side for mirrors and the opposite side for lenses.
- **Dropping the sign of f.** Diverging devices have negative f.
- **Expecting a real image from a diverging device.** With a real object it never happens.

## One-minute recap

Real image: d<sub>i</sub> positive, inverted, projectable. Virtual image: d<sub>i</sub> negative, upright, not projectable. Converging devices can make either, depending on whether the object is beyond or inside f. Diverging devices make only virtual, upright, reduced images.

:::quiz
Q: What sign does the image distance have for a virtual image?
A: Negative, in the convention 1/f = 1/do + 1/di.
Q: A real object is placed beyond the focal point of a convex lens. Is the image real or virtual, upright or inverted?
A: Real and inverted.
Q: Which devices produce only virtual images from a real object?
A: Plane mirrors, convex mirrors and concave (diverging) lenses.
Q: A concave mirror (f = 12 cm) has an object 6 cm away. What is the image distance?
A: 1/di = 1/12 - 1/6 = -1/12, so di = -12 cm, a virtual image behind the mirror.
Q: Where does a real image form for a lens versus a mirror?
A: For a lens, on the side opposite the object. For a mirror, on the same side as the object.
:::
